# Student Performance Data Analyzer

## About the Project
The Student Performance Data Analyzer is a beginner-friendly Python project that analyzes student marks and generates a performance report.

## Features
- Data validation for student marks
- Calculates total and average marks
- Identifies pass/fail results and grades
- Finds the class topper
- Performs subject-wise average analysis
- Calculates overall class performance
- Visualizes student marks and subject averages using Matplotlib

## Technologies Used
- Python
- Matplotlib

## Key Learnings
- Python lists and loops
- Conditional statements
- Data validation
- Data analysis and calculations
- Data visualization using bar charts

## Future Improvements
- Read student data from a CSV file
- Analyze larger datasets
- Add more charts and insights
